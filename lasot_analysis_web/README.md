# LaSOT 测试集分析工具

用于比较 LaSOT 类数据集的真值与跟踪预测结果，提供多序列概览、IoU/中心距离曲线和逐帧详细视图。

## 运行

```powershell
python main.py
```

## 数据结构

单序列目录需包含 `img/`、`groundtruth.txt`、`full_occlusion.txt`、`out_of_view.txt`。多序列数据集可以在任意分类目录下包含多个这样的序列目录。预测结果 TXT 的文件名（不含扩展名）必须与序列目录名相同。

数据集首次打开时只建立序列目录索引，不进入任何 `img` 文件夹。导入预测结果后，仅解析名称匹配的序列并读取一张首帧预览；双击进入详细视图时才枚举该序列的全部图片路径，枚举结果会在本次运行期间缓存。

## 交互

- 双击概览行进入详细视图。
- 折线图使用鼠标拖动或 `←`/`→` 选择帧，双击轨道直接跳转。
- 在详细图表上按 `Ctrl+滚轮` 缩放横轴；帧移动到可见边界外时视窗会自动跟随。
- 图像画布使用 `Ctrl+左键拖动` 平移、`Ctrl+滚轮` 以光标为中心缩放、`Ctrl+空格` 复位。
- 详细页顶部的“搜索区域模式”可以选择真值/预测区域分别跟随各自上一帧，或让两个区域同步跟随上一帧真值/预测框。

## 打包 EXE

```powershell
.\build.ps1
```

产物位于 `dist/LaSOT_Analysis.exe`。
